# Contributing

Open an issue for a banner Cookie Eater cannot handle, or send a focused pull request with a regression fixture.

Use the commands in the README to run the policy, browser, and native tests. Consent changes should cover misleading controls and the unavailable-model path as well as the successful flow. A model classification or a vanished banner is not sufficient proof that optional cookies were rejected.

Keep inference and browsing data local. Do not add telemetry, credentials, signing identities, or captured personal browsing data. Use your own local keychain for signing.

Contributions are licensed under Apache 2.0.
